# Zigbox is Apache-2.0

*Decided 2026-11-19, by the owner.*

The owner decided: "Apache 2.0, forever." Zigbox is licensed Apache-2.0 from now on. The root `LICENSE` is the full, unmodified Apache License 2.0 text, and every place that names the licence says `Apache-2.0` (the SPDX id in `build.zig`, the deb, rpm and SBOM metadata, the Homebrew formula as `all_of: ["Apache-2.0", "GPL-2.0-only"]`, the GPL part being the bundled kernel).

The 0.3.0 to 0.5.3 releases shipped under MIT (copyright line "DailyWombat"). Those releases, their notes, retros and evidence stay as they were.

The licence text has its own bound, `constants.package_license_bytes_max` (32 KiB). It was read under `package_description_bytes_max` (4096), and the Apache text is about 11.3 KB, so `zbx packages` failed with `StreamTooLong` in `demo-m8-packages`. A description is a short text; a licence is a fixed legal text of unlike size, so the two bounds stay apart. The deb `copyright` file and the rpm licence file carry the text as a plain file; the `License` field carries only the short SPDX id (`package_name_bytes_max`).
